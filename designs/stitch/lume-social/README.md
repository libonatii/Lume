# Lume Social — referência do Stitch

- Projeto: Lume Social Feed Redesign (`5451832634560597098`).
- Tela: Lume Social (`c6ca3f9cb11c4bc7a2afc1dd447a81f9`).
- `reference.html` e `reference.jpg`: arquivos originais obtidos pela ferramenta autenticada `download_file` do Stitch; as URLs hospedadas exigem autenticação.

A implementação React usa o CSS existente do Lume, sem executar o Tailwind ou os handlers de simulação do HTML de referência. Preserva a casca, as paletas, a fonte local, os botões cápsula e os recursos reais de amizade, mensagens, ranking e colaboração. O feed usa a API e o banco; nomes, publicações, conquistas e presença fictícios da referência não foram incorporados ao produto.
